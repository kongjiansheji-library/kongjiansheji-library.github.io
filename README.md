# 材料贴图库

按材料、厂家、颜色与用途检索贴图，支持型号搜索、收藏、平铺与原尺寸大图。

## 数据来源
- ambientCG：957张，CC0。https://docs.ambientcg.com/license/
- Poly Haven：70张，CC0。https://polyhaven.com/license
- LX Hausys / BENIF：718张独立产品图片，版权归厂家；使用与再发布以厂家授权为准。
- Pinterest：15张参考图，原作者与授权未确认。

网站源码与素材图片的权利分别归其权利人所有；本仓库没有将厂家或Pinterest图片授权为CC0。

## 运行与发布
静态网站，无需安装依赖。GitHub Pages选择main分支的根目录发布。

收藏保存在当前浏览器。完整PBR材质包通过各素材原站链接获取。
